Connecter les rappels de Masse

Cette page crée les clés sur cet appareil. Elle ne les envoie à aucun serveur et ne les conserve pas après fermeture.

Ouvre cette page sur ton Mac, puis génère les clés une seule fois pour ce service.

À copier dans Cloudflare

Dans masse-app → Paramètres → Variables et secrets → Ajouter une variable, crée ces trois valeurs avec le type Secret, en environnement Production. Copie les noms exactement.

La clé privée et le code de connexion doivent rester privés. Ne les publie pas sur GitHub et ne les partage pas en capture d’écran.

Garde cette copie dans un emplacement privé. Tu retrouveras le code PAIRING_TOKEN pour connecter ton iPhone. Réutilise ces mêmes clés ; en générer de nouvelles nécessiterait de reconnecter ton téléphone.

Ensuite, dans Masse sur ton iPhone

Ouvre Masse depuis l’écran d’accueil, puis Rappels des repas. Renseigne l’adresse HTTPS du Worker Cloudflare, le code PAIRING_TOKEN et le fuseau Europe/Paris. Active les rappels et envoie un test. Les notifications sont actives seulement une fois le téléphone connecté.
