# Masse — Nutrition

Mini-app PWA de prise de masse conçue pour iPhone.

## Fonctions
- planning quotidien des repas
- suivi calories / protéines / glucides / lipides
- meal prep de 1 à 7 jours
- liste de courses automatique
- suivi du poids et moyenne 7 jours
- stockage local sur l’appareil
- fonctionnement hors ligne
- vérification automatique des mises à jour lorsque l’app est en ligne

## Installation sur iPhone
Une fois GitHub Pages activé, ouvrir l’URL du site dans Safari puis :
Partager → Sur l’écran d’accueil → Ajouter.

Les données de suivi sont conservées localement dans le navigateur de l’iPhone.
